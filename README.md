# BotTrunk

Marketplace where AI agents pay per call for services — code or human-fulfilled — over x402 (USDC on Algorand for the Global x402 Challenge; other rails later).

Monorepo:

- `gateway/` — Rails 8.1 app: service registry, x402 paywall + proxy, public catalog, seller dashboard.
- `mcp-hub/` — (coming) MCP server exposing the catalog as payable tools.

See `CLAUDE.md` for the conventions and `gateway/README.md` to run it.
